# Política de Seguridad

## Versiones Soportadas

| Versión | Soportada |
|---|---|
| 1.0.x | Sí |
| < 1.0 | No |

## Reportar Vulnerabilidades o Fallos Críticos

Si descubres una vulnerabilidad o un fallo crítico de seguridad que afecte a la estabilidad del entorno de ejecución o a los datos de guardado:

1. Por favor, abre una incidencia privada o envía un correo a través del perfil del autor.
2. Proporciona pasos de reproducción detallados y archivos de registro de RPH (`RagePluginHook.log`).
